## 一句話總結

Terry 主張 AI 會放大而非消除工程差距：能定義問題、理解資料結構與領域基礎、設計可擴展系統並逐步控制 agent 品質的人，才有能力把 prototype 變成 production。

## 核心重點

- 北美工程需求沒有整體消失，但裁員、重組與 AI 對 junior 的衝擊較大；節目以從業體感多於市場數據。
- AI coding 面試不是讓模型代答，而是觀察候選人如何給 context、切任務、判斷輸出並解釋設計取捨。
- Foundation 包含資料結構／演算法與各領域底層知識；practical sense 則由實作、測試、review 與 agent 協作共同建立。
- System Design 是在規模、延遲、資料、安全、可靠性與成本間取捨；RAG、向量資料庫、agent workflow 與 GPU inference 是新的設計面向。
- 高階需求一次丟給 agent 容易產生錯誤路徑；Terry 偏好逐步 build、檢查 plan，並要求模型提出替代方案。

## 實用性評估

System Design、AI 面試與品質控制段落扎實，來自長期一線經驗；但整集有大量課程銷售、個人稅務、加密資產、Tesla 與 AI 毀滅／奇異點推測，技術密度被明顯稀釋。

## 批判分析與風險標記

- 對北美需求、junior 被取代與「AI 會創造更多工程需求」均缺乏就業數據，結論互有張力。
- 現代 System Design 實戰營在節目中占比很高，內容判斷與商業宣傳需分開。
- 「個人稅務多數可自己處理、問 AI／看法規即可」可能造成法律與申報風險；複雜跨境情境仍應找合格專業人士複核。
- 以太坊、Circle、Tesla、科技股與回調買點屬個人持倉觀點，不是投資研究；節目雖口頭免責，仍有強烈看多導向。
- AI 毀滅人類、2026 奇異點與全面生成式 UI 是高度不確定推測。
