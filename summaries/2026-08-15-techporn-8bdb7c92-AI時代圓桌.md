## 一句話總結

四位工程師／創業者以 Nvidia 技術堆疊與自身工作流為背景，討論如何讓 agent 長時間自主工作，結論是 PRD、任務拆解、checkpoint、測試閉環與 product sense 比單次 coding 更稀缺。

## 核心重點

- Nvidia 的價值被描述成從能源、晶片、基礎設施、模型到應用的垂直堆疊，但節目也混入出口管制與持股討論。
- 24 小時 agent 必須能讀取明確待辦、在 checkpoint 回報、以 hooks／lint／tests 自我驗證，偏離時停止或回復。
- PRD 被稱為新的 source code：需求越清楚，AI 越能拆解；細節太死也可能限制模型提出更好的方案。
- 小型個人 app 不一定需要全自動流程；大型、多服務或 on-call 工作才更能回收 harness 成本。
- 實作愈便宜後，值得解決的問題、產品體驗、優先級與跨 agent 的脈絡管理更重要。
